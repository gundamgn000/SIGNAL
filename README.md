# SIGNAL — 獨立部署版

此專案為純 HTML / CSS / JavaScript 靜態網站，不需要 ChatGPT 登入、API 金鑰或建置工具。

## 檔案
- index.html：網站首頁
- style.css：響應式版面與動畫樣式
- app.js：文章、課程、學習清單與粒子開場

## 本機預覽
在解壓縮資料夾執行 `python -m http.server 8000`，開啟 http://localhost:8000。

## 部署
將 index.html、style.css、app.js 放在靜態網站的發佈根目錄。無需安裝套件或執行 build。可以使用靜態主機，或將資料夾內容上傳到自己的 Git 儲存庫，再由支援靜態網站的平台部署。

## 外部依賴
字體由 Google Fonts 載入；無法連線時會使用系統字體。新聞來源連結開啟外部官方網站。

## 正式公開前
- 課程、價格與課綱仍是示範內容，沒有付款或影片交付功能。
- 學習清單儲存在使用者瀏覽器 localStorage，不會建立訂單。
- 需以真實品牌、聯絡方式和服務內容替換概念展示資訊。
- 時事內容為固定文章，並非自動更新。
- 請在目標瀏覽器與手機檢查動畫、排版、鍵盤操作與連結。

## 開場
直接進入首頁時播放。網址帶有 # 錨點或使用者啟用減少動畫時略過；亦提供略過按鈕與 Esc。

本匯出包含目前網站的三份前端原始碼，不含 Sites 身分、部署憑證或 Git 歷史。
